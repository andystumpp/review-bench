# Review Bench for VS Code

Every decision your code makes, journey by journey, in plain words, inside VS Code.

Run **Review Bench: Open** in a workspace. Review Bench reads the workspace,
draws the map, traces each journey, and shows the decision trees, the test
cases and the screens. Ask, What if and search work too. Every AI step goes
to the Copilot you are signed in to in VS Code; the first time, VS Code asks
you to allow Review Bench to use it. Nothing else leaves your computer.

**Save report** writes `report.html`, the same page the daily GitHub Action
publishes, to share or open later.

Settings: `reviewBench.model` (which Copilot model, or empty to let Review
Bench pick; **Review Bench: Choose the model** lists them) and
`reviewBench.look` (`plain` or `full`).
